# My Money — Family Finance Manager

A mobile-first household income and expense tracker.

Features: dated income and expense entries, editable history, all-time balance, monthly dashboard, weekly and monthly reports, category breakdown, CSV export, print, JSON backup and restore.

Data is stored in this browser on this device. It does not sync between devices or provide cloud backups. Use Backup & settings to download backups regularly.

GitHub Actions deploys the static app to GitHub Pages on every push to main. In repository Settings → Pages, select GitHub Actions as the build and deployment source if it is not already selected.
